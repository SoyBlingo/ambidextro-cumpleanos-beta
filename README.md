# Ambidextro: Un cumpleaños dividido — Beta

Beta de cumpleaños para Yislehin, basada en la versión 48.

24 niveles, 8 mundos y 60 segundos por nivel. Controles: W/A/D y flechas; S/flecha abajo para bajar. El botón Saltar nivel permite revisar la beta.

El video final aún no está incluido. Se puede cargar localmente en Preparar la sorpresa.

Publicación: GitHub Pages, rama main, carpeta raíz.
